# DSA01 Assignment 1 – Simple C++ Codes

These are simplified beginner-level example programs for Tasks 1–12.

## Compile
Example:
```bash
g++ -std=c++17 -Wall -Wextra Task06/Task06.cpp -o task06
```

Windows PowerShell:
```powershell
.\task06.exe
```

Compile each C++ file separately because each file has its own `main()` function.

## Before submitting
- Run every program yourself.
- Save your own output screenshots in the matching task folder.
- For Tasks 4 and 5, write predicted output before running the code.
- Add your name, register number and compiler version to your report.
- The assignment also requires theory answers, UML diagrams, pseudocode, test tables, alternative-concept explanations and Big-O analysis. Code alone is not the full assignment.
- Check that your instructor accepts this simplified level of implementation.
